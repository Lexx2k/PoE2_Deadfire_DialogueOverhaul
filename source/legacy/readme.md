# Pillars of Eternity II - Deadfire - Vertical Dialog Interface

This mod adds a modern, vertical dialog interface to the game. Enabled by default, can be disabled again in the settings (or toggle with F10).

## Installation

Copy the included `PillarsOfEternityII_Data` folder into the game's `Pillars of Eternity II` folder, beside `TidesOfNumenera.exe`, merging folders and replacing files when prompted. For Steam, this is usually `steamapps/common/Pillars of Eternity II`.
